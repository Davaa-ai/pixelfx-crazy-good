Sanguine ArcanaA test pack: dark-fantasy love archetypes as animated tarot cards and one-shot omens, drawn entirely in code on the pixelfx engine. Click any piece to replay it.

Everything lives in labs/sanguine-arcana/ and imports only src/core. Delete that one folder to remove it; to keep a piece, move its file into src/fx/<category>/ and run node tools/index.mjs.
